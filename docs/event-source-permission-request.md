# Event Source Permission Request

Use this draft with each source owner. Send a separate request per provider and retain the written response with the project’s source-access records. Do not enable a provider unless the response covers the intended collection and reuse below.

## Draft

**Subject:** Permission request for automated event-calendar integration with Kllctrs

Hello,

We are building Kllctrs, a U.S. collectibles event discovery platform. We would like your written permission to collect event-calendar information from **[source name and URL]** and make those event facts available to collectors in Kllctrs.

Please let us know whether you authorize Kllctrs to:

- retrieve event listings and detail pages automatically, on a schedule you approve;
- store event facts such as title, dates, venue, city/state, organizer contact details, categories, and the source URL;
- display those facts in our event directory with attribution and a link back to your original listing;
- periodically check for updates and mark events as changed, cancelled, or stale when your source indicates that;
- retain a limited history of source observations for deduplication and correction review.

We will keep each imported event pending human review before it becomes public. We will not collect or republish images, logos, article text, or other expressive media as part of this request unless you separately authorize those uses. We will follow any rate limits, attribution format, caching duration, geographic/category limits, and removal process you specify. If you offer an API, feed, or preferred partnership process, please point us to it.

Please confirm the permission scope, any conditions or limits, and the contact to notify about technical issues or removal requests. If this request should go to another person, we would appreciate being directed to them.

Thank you,

**[Name]**  
**[Role / Kllctrs]**  
**[Contact email]**  
**[Kllctrs website]**

## Provider-specific references

- **Trading Card Database (TCDB):** request express written consent for automated retrieval and commercial use of event-calendar data. Its [Terms of Use](https://www.tcdb.com/TermsOfUse.cfm) prohibit robots and screen scraping and limit the site license to personal, non-commercial use.
- **Card Show Hub:** request prior written permission for automated collection and systematic retrieval. Its [Terms of Service](https://cardshowhub.com/terms) explicitly require it.
- **Sports Collectors Digest:** ask for the approved data-use terms and an API/feed or explicit written permission. Kllctrs has not verified terms that authorize automated collection.

## Enablement record

Before setting a source permission flag, record the approval date, source owner, approved URLs/data, permitted use, rate limit, retention/display requirements, renewal or expiry date, and where the written approval is retained. Keep these records outside public source control if they contain private contact details or contract terms.
